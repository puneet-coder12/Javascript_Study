For example, if you have an element with nested HTML tags, innerHTML will return the entire HTML structure, while innerText and textContent will only return the visible text content. document.querySelector('h1') // returns the first h1 element in the document document.querySelectorAll('h2') // returns a NodeList of all h2 elements in the document, which can be iterated over using a loop or converted to an array for further manipulation. but not a pure array by default const temp = document.querySelectorAll('li') temp[0].style.backgroundColor = "red" getElementsByClassName('list-item') // returns a live HTMLCollection of all elements with the class name "list-item". This collection is automatically updated when elements are added or removed from the document, so it always reflects the current state of the DOM. However, it does not have array methods like forEach or map, so you may need to convert it to an array if you want to use those methods. Array.from(document.getElementsByClassName('list-item')) // converts the HTMLCollection to an array, allowing you to use array methods like forEach, map, filter, etc. This is useful when you want to manipulate or iterate over the elements in a more flexible way.wwwww
